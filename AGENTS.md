# AGENTS.md

The project rules live in `.claude/rules/`, generated by APM from `.apm/instructions/`. Claude Code, VS Code and the Copilot CLI load them on their own. Any other agent reading this file: read the rules that match the files you touch before changing anything.

| Rule                                  | Applies to             |
| ------------------------------------- | ---------------------- |
| `.claude/rules/project-overview.md`   | everything             |
| `.claude/rules/commands.md`           | everything             |
| `.claude/rules/architecture.md`       | `src/app/**`           |
| `.claude/rules/typescript.md`         | `**/*.ts`              |
| `.claude/rules/angular-components.md` | `**/*.ts`, `**/*.html` |
| `.claude/rules/styling.md`            | `**/*.scss`            |

Skills live in `.claude/skills/`.
